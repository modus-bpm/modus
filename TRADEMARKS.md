# Name and logo

The code in this repository is licensed under the [Apache License 2.0](LICENSE). That license
covers the code. It does not give anyone the right to use the project's name or logo (section 6
of the license).

"Modus BPM" and the Modus BPM logo are used by Randy Michak to identify this project and the
software and services he offers under that name.

## What you can do without asking

- Say truthfully that your product or service works with, is built on, or is derived from
  Modus BPM.
- Use the name to refer to this project in articles, talks, reviews and documentation.
- Run unmodified releases under the name inside your own organization.

## What needs written permission

- Using "Modus BPM", the logo, or a name close enough to be confused with it as the name of a
  fork, a modified version, a product, a hosted service or a company.
- Using the name or logo in a way that suggests the project owner endorses or is responsible for
  something he did not release.

If you distribute a modified version, give it a different name and remove the logo.

To ask for permission, open an issue in this repository.
